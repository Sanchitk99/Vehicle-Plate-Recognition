    About This Project

    This system supports vehicle detection, plate detection, and full ANPR (plate detection + OCR).

    What It Does

    The application accepts an uploaded image, detects vehicles and/or number plates, and can run OCR on detected plate crops to output final plate strings. It returns annotated images plus runtime metrics.

    How It Works

    1. User uploads an image and sets a confidence threshold.
    2. Frontend calls one endpoint based on mode: /detect/vehicle, /detect/plate, or /anpr.
    3. Backend preprocesses image and runs the selected YOLO11n detector.
    4. ANPR mode crops detected plates and runs OCR with text normalization.
    5. Annotated output and metrics are returned to the UI.

    Model Metrics Explained

    Precision

    How many predicted objects are correct. Higher precision means fewer false positives.

    Recall

    How many true objects were detected. Higher recall means fewer missed detections.

    mAP@0.50

    Detection quality at IoU threshold 0.50. It is easier to score high here than stricter settings.

    mAP@0.50:0.95

    Average AP across IoU thresholds 0.50 to 0.95. This is stricter and reflects localization robustness.

    Mean / P50 / P95 / P99 Latency

    Mean is average speed. P50 is typical latency, while P95 and P99 show tail latency under slower cases.

    FPS

    Throughput estimate from latency using FPS approximately equal to 1000 divided by latency in milliseconds.

    Current Scope

    This is a practical ANPR perception module with separate vehicle and plate detectors plus OCR-based plate reading. The interface separates live detection, results, and project documentation.
